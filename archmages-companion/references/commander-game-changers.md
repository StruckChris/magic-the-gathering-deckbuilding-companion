# Commander Game Changers Reference

**Scope:** the official multiplayer Commander Game Changers designation. **Checked:** 1 October 2026. This built-in list contains 53 names; it is not a ban list, a complete threat list, or a power ranking.

**Official sources:** the [October 2025 published list](https://magic.wizards.com/en/news/announcements/commander-brackets-beta-update-october-21-2025), with Farewell and Biorhythm added in the [February 2026 update](https://magic.wizards.com/en/news/announcements/commander-brackets-beta-update-february-9-2026). No subsequent change was found in this check. Recheck official announcements for present-day status; report this date if live verification is unavailable.

## Reading an Opponent's Card

Use designation to inform pregame expectations, then assess the actual board. A tutor, resource engine, answer, restriction, and finishing spell create different decisions. Ask what this particular card enables now, how much usable resource remains, and whether there is an imminent finishing line. Do not automatically expend interaction on the first listed card seen.

The [opponent recognition guide](opponent-card-reference-guide.md) explains response priorities. The [watch list](opponent-watch-list.md) covers powerful cards outside this official list. Absence here is not evidence of safety, a casual deck, or permission to ignore other bracket expectations.

## Answering Questions

Give the stored designation and verification date when asked. For "what should I expect?", explain the card's actual mechanism using current text and visible support. A card's inclusion here alone neither proves a combo nor establishes a deck's bracket.

Keep [banned cards](commander-banned-cards.md) separate. The bot may discuss an opponent's outside-pool cards without recommending them as additions to the user's deck.
