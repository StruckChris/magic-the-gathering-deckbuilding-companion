# The Archmage's Companion Bot

A free casual Commander knowledge handoff for an agent the player already uses.

You may use, adapt, and share this pack for free, including with your own AI assistant. It is not for resale or paid bundles. See the [noncommercial license and unofficial fan-content notice](LICENSE.md).

The Companion helps players make their own idea work from the cards they have available, using old-school competitive deckbuilding styles from 2000s-era Magic. Its focus is casual Commander, especially newer players. Competitive reasoning supplies the method; tournament power is not the assumed destination.

**Begin with [Start Here](START_HERE.md).** It introduces the receiving agent to the workflow and routes six core questions to the existing material.

The pack provides coaching instructions and Magic reference material for use in an existing agent conversation. It does not include a hosted service or the player's card inventory.

## Teaching Order

**Aggro / Combo / Control primer -> Archetypical Shell primers -> Engine -> Finishers**

Understand the intended game plan, recognize a shell supported by the supplied cards, experiment with the engine, and establish how it closes a game. The categories can overlap; they are a practical decision tree, not rigid labels for individual cards.

## Core Promise

Build exclusively from the supplied, available card pool. Find contextual interactions and explain structural gaps as missing functions. Never turn a gap into an unsolicited shopping list. Outside-card suggestions require an explicit request for a particular goal.

The bot should recognize a wide range of strategies, not reproduce its creator's decks, colors, favorite cards, or playstyle. No personal decklists or collection records are included here.

## Using the Pack

Start with the entry guide, which points to the bot instructions and the references relevant to the player's request. Supporting primers are reference knowledge, not a lecture to recite in every response. A narrow interaction question should receive a narrow answer.

Each archetype primer owns its historical explanation, direct source links, sustainable-advantage lesson, and overlap with other approaches. The central list library is an index, not a second competing explanation. The 2008 retrospective and 2014 teaching articles connect the 2000s foundation to earlier roots and later developments.

Casual Commander remains the defined niche. Historical competitive play, Standard, Modern, Draft, and Sealed are supporting knowledge for explicit questions, not automatic alternate workflows.

Use only capabilities available to the receiving agent. Do not assume file retrieval, live search, permanent memory, or automatic collection imports exist.

The 2026 competitive examples are dated teaching references, not a maintained current metagame report. Refresh evidence when someone asks about the present format.

The four opponent-reference lists contain built-in card names and explanations, not just outbound links. Include them in the bot's knowledge configuration. Official lists carry verification dates; curated role and watch notes are strategic teaching material, not official categories or automatic recommendations. Recognizing an opponent's card does not authorize adding it to the player's deck.

The documents use original explanatory prose and linked sources. They contain no copied card-image library, comprehensive card database, or private sample collection.

## Who Is the Archmage

**You are.** The Companion helps the player understand and make their own decisions. The author's Magic background is described in the [bot instructions](BOT_INSTRUCTIONS.md#identity); the primers do not require access to the author's personal decks.
